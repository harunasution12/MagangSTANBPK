Sambungkan ke Google Sheets

Belum tersambung. Data hanya tersimpan di browser ini.

Teman satu tim cukup mengisi URL dan kode tim yang sama di sini, lalu klik Hubungkan. Mereka tidak perlu mengikuti panduan di bawah.

Panduan penyiapan (sekali saja, oleh satu orang)

  1. Buka sheets.new di browser untuk membuat Google Sheet baru, beri nama misalnya Log Magang.
  2. Di Sheet itu, klik menu Ekstensi → Apps Script (Extensions → Apps Script). Hapus semua isi Code.gs, lalu tempel kode di bawah ini (tombol Salin kode). Kode tim di kolom atas sudah otomatis dimasukkan ke dalam kode.
  3. Klik Simpan (ikon disket). Pilih fungsi setup di toolbar, klik Jalankan (Run). Saat diminta izin: Tinjau izin → pilih akun → Lanjutan → Buka (tidak aman) → Izinkan (Review permissions → Advanced → Go to … (unsafe) → Allow). Ini wajar karena skripnya milik Anda sendiri. Tab Peserta dan Log akan muncul di Sheet.
  4. Klik Terapkan → Deployment baru (Deploy → New deployment). Ikon roda gigi → pilih Aplikasi web (Web app). Isi Jalankan sebagai: Saya (Execute as: Me) dan Yang memiliki akses: Siapa saja (Who has access: Anyone). Klik Terapkan, lalu salin URL aplikasi web.
  5. Tempel URL itu di kolom URL Web App di atas, lalu klik Hubungkan. Data yang sudah ada di browser ini akan ikut diunggah ke Sheet.
  6. Untuk versi GitHub: tempel URL yang sama ke sheetsUrl di bagian PENGATURAN paling atas file index.html, supaya semua orang otomatis tersambung.

Jika nanti kode diubah, terapkan ulang lewat Terapkan → Kelola deployment → Edit → Versi: Versi baru agar URL tetap sama. Jangan sebarkan URL dan kode tim ke luar tim.
